# Kindling

**A Bible app for teenagers. "Small sparks. Real fire."**
Anchor verse: Luke 24:32 (KJV) — *"Did not our heart burn within us..."*

Kindling is card-first, quick to open, and built to turn a small daily spark
into a real, lasting faith. Built for teens, guys and girls — deliberately not
juvenile and not skewed to one audience.

**KJV only. Public domain. Never hardcode verse text.**

## The four v1 features

1. **Cards** — short, tappable daily Scripture cards (front = verse, flip = Real Talk + Spark + Share).
2. **Bible (KJV)** — a clean, offline King James reader.
3. **Prayer Journal** — a private space to write and keep prayers.
4. **Serve Time** — service-hour tracking for NHS and scholarship applications. The key differentiator.

## What's in this repo

- **`index.html`** — a working front-end **prototype** of all four features. Open
  it in a browser, or view the hosted version. This is a reconstruction built
  from the brief and card spec below, not the original source code (see note).
- **`docs/KINDLING_CLAUDE.md`** — the product brief. The source of truth for what Kindling is.
- **`docs/kindling-card-spec-and-31-days.md`** — the card layout spec and all 31 launch cards (KJV, with Real Talk + Spark).
- **`docs/kindling-kjv-migration.md`** — the licensing rationale and the plan to keep every verse KJV.

## Note on the original app

An earlier, nearly-finished version of Kindling was built in Claude sessions and
was lost before it was committed to version control. The files here are the
recovered planning documents plus a faithful front-end reconstruction. If the
original code turns up, it should replace `index.html` and the
`[FILL IN FROM SOURCE]` sections of the brief.

**Lesson, in one line: commit and push. Work that only lives in a session or an
uncommitted working directory can disappear.**
